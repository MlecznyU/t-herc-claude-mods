# t-herc-claude-mods

A small marketplace of mods for Claude Code. Unofficial: not made or endorsed by Anthropic.

## Install

Add the marketplace once, then install any plugin from it:

```
/plugin marketplace add MlecznyU/t-herc-claude-mods
/plugin install dialogue-box@t-herc-claude-mods
```

## Plugins

| Plugin                       | What it does                                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| [dialogue-box](./dialogue-box) | macOS only. Hear Claude's replies as short spoken paragraphs in a dialogue box you can rewind, pause, skip and speed up, in any language. |
